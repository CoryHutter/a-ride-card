A-Ride Suspension

Rider page maker. Make one page per NFC tag: a whole bike, or just the fork or shock if the family swaps parts. On a return visit, tap Open from site, pick the bike, change what you changed and tap Publish. The service log fills itself in and the tag keeps working.

One-time setup on this phone

The Publish button needs a key from GitHub so it can put pages on your site. You do this once per phone or iPad.

  1. In Safari, sign in to github.com and open Settings → Developer settings → Personal access tokens → Fine-grained tokens. Or tap this shortcut.
  2. Name it rider page maker. Set Expiration to 1 year (or longer).
  3. Under Repository access, pick Only select repositories and choose a-ride-card.
  4. Under Permissions → Repository permissions, set Contents to Read and write.
  5. Tap Generate token, copy it (it starts with github_pat_), and paste it below.
